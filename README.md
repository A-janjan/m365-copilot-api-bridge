for linux make sure to install:

```
# Microsoft's official repo
sudo apt install microsoft-edge-stable
# or download the .deb from https://www.microsoft.com/edge/download/insider
```


If you don't want to install Edge, run:

```
copilot-openai-proxy serve --no-launch-edge
```
